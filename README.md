**О проекте**

Голубая версия мобильного веб-приложения для формирования полезных привычек. Вместо дневников и напоминаний здесь упор на визуальную обратную связь: пользователь сам фиксирует, что сделал нужное действие за день, а система наглядно показывает прогресс и удержание ритма на протяжении недели. Итог — простой способ не потерять начатую привычку.

**Возможности**

- Просмотр всех привычек одним списком: название, короткое описание, текущее состояние на сегодня и отметка о выполнении.
- Добавление новых привычек с проверкой ввода: название — до 50 символов, описание — до 200.
- Редактирование уже созданных привычек и их удаление вместе со всей историей отметок по ним.
- Раздел статистики: сводка за последние 7 дней, где видно, в какие дни был прогресс и сколько всего отметок набрано за неделю.
- Счётчик на главном экране показывает, сколько привычек из общего числа закрыто сегодня.

**Технологии**

- Язык разработки: Dart.
- Фреймворк: Flutter (Material 3), светлая цветовая схема с голубым акцентом.
- Хранение данных: SQLite (пакет `sqflite`), для работы на настольных системах подключён модуль `sqflite_common_ffi`.
- Поддержка платформ: Android, iOS, web, Windows, macOS, Linux.
- Все данные живут локально на устройстве — серверная часть не используется.
