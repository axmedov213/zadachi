# habit_tracker_blue

Трекер привычек на Flutter — светлая тема с голубыми акцентами.

Реализует то же задание, что и [habit_tracker](https://github.com/OlegNemchinov/habit_tracker), но в новом дизайне.

## Функционал

- **Главный экран** — список всех привычек: название, чекбокс (выполнено / не выполнено за сегодня), счётчик «N из M», кнопка добавления.
- **Экран добавления / редактирования** — название (до 50 символов), описание (до 200), сохранить / удалить.
- **Экран статистики** — лента последних 7 дней с индикацией выполнения.

## Стек

- Язык: Dart
- Фреймворк: Flutter (Material 3, светлая тема)
- БД: SQLite (`sqflite`)

## Структура

```
lib/
├── main.dart                    # точка входа, тема приложения
├── database_helper.dart         # модель Habit + работа с БД
└── screens/
    ├── habit_list_screen.dart   # главный экран
    ├── habit_edit_screen.dart   # добавление/редактирование
    └── stats_screen.dart        # статистика за 7 дней
```

## Сборка

1. Установите Flutter SDK.
2. В корне проекта выполните:

```
flutter pub get
flutter run          # запуск на подключённом устройстве/эмуляторе
flutter build apk    # сборка APK для Android
```
